## 优惠码：现在到底有没有能用的

先把机制说清楚：搬瓦工的优惠码是循环折扣，买的时候打折多少，以后续费、升级都按同样比例折扣，不是一次性的。

力度方面，中文跟踪站记录的历史高点是 2025 年双十一的全场 11% 循环码，2026 年 2 月出现过约 6.8% 的循环码 NODESEEK2026。但各家跟踪站的更新并不一致：有的页面在 8 月还测到 6.5% 左右的循环码有效，9 月的更新则直接标注所有优惠码已失效、建议直接购买。

所以最靠谱的做法不是抄任何列表，而是下单时自己验一次：把套餐加入购物车，进入结算页，在 Promotional Code 一栏填码点 Validate Code，价格变了就是有效，没变就当没有。

> 结账页的优惠码框是唯一的最终裁判。任何第三方列表（包括历史上的 5.5% 老码）都只能当参考，验证无效就别纠结，直接按原价下单，搬瓦工的价差本来也不大。

**流量用超了怎么办？** 官方 KB 写得很直白：不收超额费，流量用完当月 VPS 会被自动暂停，到下个月恢复。不会产生账单惊吓，但业务会中断，重要服务要留意流量水位。

**拿来建站够用吗？** 20G PROMO 跑个人博客、轻量应用没问题，1 GB 内存装个宝塔面板再加 WordPress 也在合理范围内。真正要做电商或对国内访问质量敏感的业务，ECOMMERCE SLA 系列的 CN2 GIA 回程和 99.99% SLA 才是对口的选择，它机房的合规认证（SOC 2、ISO 27001 等）也齐。

**续费会涨价吗？** 官方体系里续费按购买时的价格走，优惠码折扣也是循环的，所以老用户的成本是锁定的。这也是它在中文圈口碑稳的核心原因之一。

**客服怎么联系？** 只能开工单，后台 Support → Tickets 提交。多篇教程的反馈是工作日一般 24 小时内回复，快的话一小时左右，周末客服不上班，急事别拖到周五晚上。

另外服务条款里有个细节值得知道：持续 4 小时以上以超过 100 MiB/s 的速率做磁盘 IO 会被提醒，拿它当下载中转站的话要悠着点。
